# 🎯 وثيقة مركز القيادة والعمليات والتحكم بدورات الحياة والتحليلات الشاملة
**Operations Command Center, Operational Lifecycles, Real-Time Analytics & Growth KPIs**

---

## 1. لوحة إحصائيات الإدارة العامة ومركز القيادة والعمليات (Operations Command Center)

يُعتبر **مركز القيادة والعمليات (Operations Command Center)** المنظومة المركزية العليا المخصصة لقيادة منصة **ليلة** وتوفير الرؤية اللحظية لمجريات التشغيل، الحركة المالية، أداء السيرفرات، والتدفق الحقيقي للمستخدمين والطلبات عبر مختلف أنحاء المملكة العربية السعودية.

```
+-----------------------------------------------------------------------------------+
|                     Lailah Master Operations Command Center                       |
+-----------------------------------------------------------------------------------+
| [📊 إجمالي الإيرادات الموحدة] [🏛️ القاعات والخدمات المعتمدة] [📝 الحجوزات النشطة BKG] |
| [⚡ إشارات المراقبة الفورية]  [⏳ قوائم معالجة الاعتمادات]   [💳 العمولات والضرائب INV]  |
| [🗺️ خريطة الفعاليات الحية]   [🚨 مركز التنبيهات والبلاغات]   [📈 مؤشرات النمو والتدفق]  |
+-----------------------------------------------------------------------------------+
```

### 1.1 المكونات والوحدات الرئيسية لمركز القيادة
1. **شريط المؤشرات الحية السيادية (Live Sovereign KPI Bar):**
   - **إجمالي المبيعات الموحد:** دمج إيرادات حجوزات القاعات والأماكن (`BKG-YY-XXXXXXXXXX`) مع طلبات الخدمات المساندة (`SRV-YY-XXXXXXXXXX`).
   - **صافي أرباح المنصة:** احتساب حصة العمولات المقتطعة آلياً بحسب باقات الشركاء المفتوحة.
   - **الضريبة المجمعة (ZATCA 15%):** إجمالي المبالغ الضريبية المسجلة بالفواتير الموحدة `INV-YYXXXXXXXXXX`.
   - **حجم الفعاليات النشطة المباشرة:** عدد الفعاليات التي تُقام حالياً في مختلف القاعات.
2. **رادار المراقبة اللحظية والتحركات الفورية (Live Operations Radar):**
   - متابعة التدفق المباشر للطلبات الواردة، الحجوزات المؤكدة، والتحويلات المالية الصادرة `REV-YY-XXXXXXXXXX` و `EXP-YY-XXXXXXXXXX`.
3. **مركز البلاغات العاجلة والحرجة (Critical Alerts Engine):**
   - رصد انقطاعات الاتصال، التذاكر ذات الأولوية الحرجة (P1)، وتجاوزات اتفاقيات مستوى الخدمة (SLA).

## 2. نظام التحكم الشامل بدورات الحياة التشغيلية (Operational Lifecycles Engine)

يتحكم هذا النظام بجميع المراحل والحالات البرمجية التي تمر بها العناصر الرئيسية في المنظومة من لحظة الإنشاء وحتى الأرشفة أو الإغلاق النهائي.

```
                  ┌───────────────────────────────────────────┐
                  │    محرك التحكم بدورات الحياة (Lifecycles) │
                  └─────────────────────┬─────────────────────┘
                                        │
     ┌──────────────────────┬───────────┴───────────┬──────────────────────┐
     ▼                      ▼                       ▼                      ▼
┌─────────┐            ┌─────────┐             ┌─────────┐            ┌─────────┐
│  الحجز  │            │  الأصل  │             │  الطلب  │            │  المالية │
│ Booking │            │  Asset  │             │ Service │            │ Finance │
└─────────┘            └─────────┘             └─────────┘            └─────────┘
```

### 2.1 دورة حياة حجز القاعة (`Hall Booking Lifecycle`)
1. **الإنشاء والطلب المبدئي:** قيام العميل بتحديد التاريخ والقاعة والخدمات المضافة، وتوليد معرف الحجز القياسي `BKG-YY-XXXXXXXXXX`.
2. **التسعير والفلترة:** احتساب ضريبة 15% وعمولة المنصة آلياً، وتوليد الفاتورة الضريبية `INV-YYXXXXXXXXXX`.
3. **الدفع والتأكيد (`Confirmed`):** تأكيد الحجز وحجز تاريخ المناسبة بجدول القاعة وإرسال التنبيه الفوري للمزود.
4. **التنفيذ الميداني (`In Progress`):** فتح القاعة، توجيه المشرفين، وبدء المناسبة في موعدها.
5. **الاكتمال والتسوية (`Completed`):** تحويل صافي مستحقات المزود برقم إيراد `REV-YY-XXXXXXXXXX` وفتح خيار إضافة التقييم للعميل.

### 2.2 دورة حياة أصول القاعات والخدمات (`Asset Lifecycle`)
1. **الإضافة بوضع التعليق (`Pending Approval`):** إنشاء الأصل من لوحة المزود وتطبيق قيود الصور (`500KB`, `16:9`) والفيديو (`MP4`, `10MB`).
2. **تدقيق وتفعيل الإدارة (`Approved`):** مراجعة الإدارة ونشر الأصل بمتجر العملاء.
3. **الإيقاف والصيانة (`Maintenance / Suspended`):** تعليق استقبال الحجوزات مؤقتاً عند إجراء الصيانة أو معالجة بلاغات الجودة.

## 3. القوائم الفورية ومؤشرات النمو والتراكم (Real-Time Queues & Cumulative Growth KPIs)

### 3.1 القوائم الفورية المباشرة (Real-Time Live Queues)
- **قائمة طلبات الاعتماد المعلقة (Asset Approval Queue):** استعراض القاعات والخدمات بانتظار موافقة الإدارة.
- **قائمة التسويات المالية المعلقة (Payout Queue):** أرباح المزودين الجاهزة للصرف بعد اكتمال الفعاليات.
- **قائمة تذاكر الدعم العاجلة (High Severity SLA Queue):** التذاكر الحرجة الحالية المحددة بأقل من 15 دقيقة للاستجابة.

### 3.2 مؤشرات النمو والتحليلات التراكمية (Cumulative Growth Analytics)
1. **معدل النمو الشهري للإيرادات (MRR & ARR):** قياس التدفقات المالية المباشرة والنمو المتوقع.
2. **معدل إشغال القاعات (Venue Occupancy Rate):** نسبة الأيام المحجوزة مقارنة بإجمالي الأيام المتاحة لكل مدينة وحي.
3. **معدل الاحتفاظ بالعملاء (Customer Retention & LTV):** نسبة الحجوزات التكرارية والربحية التراكمية لكل عميل بناءً على برنامج الولاء.
