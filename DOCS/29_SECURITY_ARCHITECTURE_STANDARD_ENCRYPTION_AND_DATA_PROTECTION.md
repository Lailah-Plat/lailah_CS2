# 🛡️ وثيقة معمارية الأمان، التشفير المعياري وحماية البيانات وحجب الثغرات
**Security Architecture, Standard Encryption (At-Rest & In-Transit), Data Protection & Anti-Vulnerability Engine**

---

## 1. معمارية الأمان متعددة الطبقات (Defense-in-Depth Security Architecture)

تُعتبر **منصة ليلة** منظومة حيوية تتعامل مع بيانات شخصية، عقود منشآت، وعمليات مالية سيادية. اعتُمدت معمارية أمنية متعددة الطبقات لحماية كافة مكونات النظام بدءاً من المتصفح وحتى السيرفرات وقواعد البيانات.

```
+-----------------------------------------------------------------------------------+
|                    Lailah Defense-in-Depth Security Layers                        |
+-----------------------------------------------------------------------------------+
|  [🌐 طبقة الحماية الأمامية Front-End] (HTTPS, XSS Sanitization, Input Validation) |
|  [🛡️ طبقة الجدار الناري WAF & Rate Limit] (DDoS Mitigation, IP Throttling)       |
|  [🔑 طبقة الهوية والمصادقة Auth & RBAC] (JWT, bcrypt, Session Revocation)        |
|  [⚡ طبقة الوسائط والسيرفر Server Logic] (API Gateways, Secrets Vault)           |
|  [🔒 طبقة التشفير وقواعد البيانات Storage] (AES-256-GCM, TLS 1.3, DB Isolation)  |
+-----------------------------------------------------------------------------------+
```

## 2. آليات وتطبيقات التشفير المعياري (Standard Encryption Protocols)

تُطبق المنصة أعلى معايير التشفير الدولية المعتمدة لحماية البيانات في جميع حالاتها (سواء أثناء النقل أو التخزين).

```
                  ┌───────────────────────────────────────────┐
                  │    محرك التشفير المعياري (Crypto Engine)   │
                  └─────────────────────┬─────────────────────┘
                                        │
     ┌──────────────────────┬───────────┴───────────┬──────────────────────┐
     ▼                      ▼                       ▼                      ▼
┌─────────┐            ┌─────────┐             ┌─────────┐            ┌─────────┐
│ التشفير │            │ التشفير │             │ تشفير   │            │ التوقيع │
│ المباشر │            │ أثناء   │             │ كلمات   │            │ الرقمي  │
│ At-Rest │            │ النقل   │             │ المرور  │            │ HMAC    │
└─────────┘            └─────────┘             └─────────┘            └─────────┘
```

### 2.1 جدول مواصفات التشفير المعتمدة بالنظام

| مجال التشفير (Domain) | الخوارزمية والمعيار (Algorithm) | مفتاح التشفير / المعاملات | الشرح والوظيفة الأمنيّة |
| :--- | :--- | :--- | :--- |
| **البيانات المخزنة (At-Rest)** | `AES-256-GCM` | مفاتيح سحابية مشفرة 256-bit | تشفير قاعدة البيانات والتخزين السحابي للبيانات الحساسة والحسابات البنكية IBAN. |
| **البيانات أثناء النقل (In-Transit)** | `TLS 1.3` (مع TLS 1.2 كحد أدنى) | شهادات معتمدة مشفرة 2048-bit | تشفير القنوات وجميع الاتصالات بين المتصفح، السيرفر، وبوابات الدفع الإلكتروني. |
| **كلمات مرور المستخدمين** | `bcrypt` مع Salt عشوائي | `Cost Factor = 12` | التشفير غير القابل للفك لكلمات المرور وتخزين الـ Hash فقط بقاعدة البيانات. |
| **التوقيع الرقمي للـ Webhook** | `HMAC-SHA256` | Secret Keys مخفية بالسيرفر | التحقق الرقمي من مصداقية الرسائل الواردة من بوابات الدفع الإلكترونية. |
| **رمز المصادقة للجلسات** | `JWT (JSON Web Token)` | `RS256` asymmetric keys | توقيع رموز الجلسات بمفتاح خاص والتحقق منها بمفتاح عام لمنع التلاعب والتزوير. |

## 3. الوقاية والحماية من الثغرات البرمجية الشائعة (Vulnerability Mitigation Engine)

تم بناء التطبيق مع حجب آلي وتام لأشهر الهجمات والثغرات الأمنية المحددة في معايير OWASP Top 10:

### 3.1 آليات حجب الثغرات البرمجية

1. **الوقاية من ثغرات حقن النصوص الخبيثة (Cross-Site Scripting - XSS):**
   - تطهير وتحقيم (Sanitization) جميع المدخلات في الواجهة الخلفية قبل المعالجة والتخزين.
   - تفعيل رأس الأمان `Content-Security-Policy (CSP)` لمنع تنفيذ أي سكربتات غير مصرح بها.
2. **الوقاية من ثغرات حقن الأوامر وقواعد البيانات (SQL / NoSQL Injection):**
   - استخدام الاستعلامات المجهزة (Parameterized Queries) والربط الآمن المعتمد في الـ ORM المعتمد بالمنظومة (`src/db/schema.ts`).
   - حظر تركيب أو تنفيذي أي أوامر SQL عشوائية صريحة من مدخلات العميل.
3. **الوقاية من هجمات التخمين والإغراق (Rate Limiting & Anti-Brute Force):**
   - تحديد سقف الطلبات (Max Requests Limit) لصفحات تسجيل الدخول واستعادة كلمة المرور لـ **5 محاولات لكل دقيقة**.
   - إغلاق الحساب مؤقتاً عند تجاوز محاولات الدخول الفاشلة المتتالية.

## 4. فحص الأمان للوسائط والمرفقات (Media Payload Security Engine)

تُطبق المنصة فحصاً حازماً ورفضاً آلياً لأي ملفات مرفوعة لا تحقق المعايير الفنية والأنماط المعتمدة منعاً لرفع ملفات تنفيدية أو خبيثة:

```
[رفع ملف صور أو فيديو] ──► [فحص الامتداد والصيغة] ──► [فحص حجم الملف] ──► [فحص الأبعاد]
                                                                          │
       ┌──────────────────────────────────────────────────────────────────┴──────────────────────────────────────────────────┐
       ▼                                                                                                                     ▼
[مطابق للمواصفات 500KB/10MB]                                                                                           [غير مطابق أو تتجاوز الحجم/الأبعاد]
       │                                                                                                                     │
       ▼                                                                                                                     ▼
 (قبول وسحب الصورة للمعاينة والاعتماد)                                                                                  (رفض آلي فوري وإرجاع رسالة خطأ آمنة)
```

### 4.1 الشروط الأمنية الحازمة للوسائط المرفوعة
- **الصور (Images):**
  - الامتدادات المسموحة فقط: `JPEG`, `JPG`, `PNG`, `WebP`.
  - الحد الأقصى للحجم: **500KB** للصورة الواحدة (رفض آلي فوري لأي صورة تتجاوز هذا الحجم).
  - القياسات والأبعاد: الأدنى `960x540` والأقصى `1280x720` بنسبة `16:9`.
- **الفيديوهات (Videos):**
  - الامتداد المسموح فقط: **MP4** القياسية لضمان الأمان والتوافق العالي.
  - الحد الأقصى لحجم الفيديو: **10MB** كحد أقصى.
  - القياسات والأبعاد: الأقصى `960x540` بدقة QHD.

## 5. الربط المعياري بالمعرفات التسلسلية والسيادة الضريبية

- **المعرفات التسلسلية الموحدة (تصفير سنوي من `0000000001`):**
  - **حجوزات القاعات:** `BKG-YY-XXXXXXXXXX`
  - **طلبات الخدمات:** `SRV-YY-XXXXXXXXXX`
  - **الفواتير الصادرة الموحدة:** `INV-YYXXXXXXXXXX` (بدون واصلة بعد السنة)
  - **الإيرادات المالية:** `REV-YY-XXXXXXXXXX`
  - **المصروفات المالية:** `EXP-YY-XXXXXXXXXX`
- **التشفير الضريبي المعتمد:**
  - توليد رمز الاستجابة السريع التشفيري (ZATCA QR Code Phase 2 B2C/B2B) بالفواتير الصادرة للحفاظ على السلامة الضريبية وعدم التلاعب بقيم ضريبة 15%.
