# 🤝 وثيقة إدارة الشركاء والاشتراكات، طلبات الانضمام والرقابة المالية السيادية
**Partners Management, Subscription Tiers, Onboarding Workflows & Financial Sovereign Governance**


## تحديث حاكم — اشتراكات المزودين والعمولات والضرائب (30-09-2026)

الباقات وعمولاتها قابلة للتغيير بقرار المنصة؛ لا تعتمد هذه الوثيقة نسبة ثابتة لأي باقة. كل نسبة ظاهرة في مثال قديم أو جدول سابق ليست التزاماً ثابتاً، ويجب أن تعرض واجهات الإدارة النسبة الحالية من إعداد الباقة مع سجل نسخ وتاريخ سريان. تثبت المعاملة المالية النسبة الفعلية التي احتسبت عليها وقت نشوئها.

المزود مسؤول عن ضريبة حجوزاته ومبيعاته وخدماته. منصة ليلة مسؤولة عن ضريبة عمولتها ومبيعاتها ورسومها الخاصة فقط. لا تعني الفاتورة أو التسوية أن ضريبة المزود تخصم كإيراد/التزام ضريبي لليلة. يجوز عرض ضريبة المزود منفصلة للمزود أو للعميل، مع إبقائها خارج دفاتر ليلة.

اشتراك الباقة ورسوم الاشتراك، عمولة الحجز، أتعاب التسويق، ميزانية الإعلان، وضريبة كل طرف بنود مستقلة. لا تخلط بين ميزة تسويقية ضمن باقة وبين عمولة أو تكلفة حملة إلا بإعداد واضح وموافقة موثقة.

## 1. إدارة الشركاء والاشتراكات ومعايير فئات المستويات (Partner Subscriptions & Tier Standards)

تُحدد باقات الاشتراك المعتمدة بالمنصة حقوق وإمكانيات الشركاء والمزودين، وتُربط ديناميكياً بنسبة عمولة المنصة المقتطعة آلياً من الحجوزات والخدمات الناجحة.

```
                         ┌──────────────────────────────────┐
                         │   باقات اشتراك الشركاء (Tiers)  │
                         └────────────────┬─────────────────┘
                                          │
 ┌────────────────────────────────────────┼────────────────────────────────────────┐
 │                                        │                                        │
 ▼                                        ▼                                        ▼
┌──────────────────────────────┐ ┌──────────────────────────────┐ ┌──────────────────────────────┐
│  الباقة الأساسية (Basic Tier)  │ │  الباقة المتقدمة (Advanced)  │ │ الباقة الاحترافية (Pro Tier) │
│ • عدد القاعات: حتى 2         │ │ • عدد القاعات: حتى 5         │ │ • عدد القاعات: غير محدود     │
│ • عمولة المنصة: حسب الإعداد المالي للباقة          │ │ • عمولة المنصة: حسب الإعداد المالي للباقة          │ │ • عمولة المنصة: حسب الإعداد المالي للباقة           │
│ • معالجة الطلبات: قياسية     │ │ • أولوية الظهور بالبحث       │ │ • أولوية قصوى ودعم اختصاصي  │
└──────────────────────────────┘ └──────────────────────────────┘ └──────────────────────────────┘
```

### 1.1 جدول مقارنة باقات الشركاء والتزامات العمولة (Partner Subscription Matrix)

| المعيار / الباقة | الباقة الأساسية (Basic Tier) | الباقة المتقدمة (Advanced Tier) | الباقة الاحترافية (Pro Tier) |
| :--- | :--- | :--- | :--- |
| **رسوم الاشتراك السنوي** | مجاني / 0 ريال | 4,999 ريال / سنوياً | 11,999 ريال / سنوياً |
| **عدد القاعات المسموح بها** | قاعتان (2 Venues) | 5 قاعات (5 Venues) | غير محدود (Unlimited) |
| **عمولة المنصة من الحجوزات** | تحددها إعدادات المنصة النشطة | تحددها إعدادات المنصة النشطة | تحددها إعدادات المنصة النشطة |
| **عمولة التسويق والحملات** | حسب النسبة المقررة بالإعدادات | وفق إعداد تسويق متغير | وفق إعداد تسويق متغير |
| **أولوية العرض بشركاء البحث** | مرتبة قياسية عادي | أولوية مرتفعة | أولوية ممتازة + شارة شريك ماسي |
| **التقارير المالية والتحليلات** | تقارير أساسية شهرية | تقارير تفصيلية لحظية | تحليلات متقدمة وتوقعات الذكاء |

## 2. إدارة طلبات الشركاء الجدد واشتراطات الاعتماد (Partner Onboarding Requests)

ضمان جودة وموثوقية الخدمات بالمنصة عبر معالجة طلبات انضمام المزودين والشركاء الجدد وفق خطوات تدقيق صارمة.

```
[تسجيل الشريك الجديد] ──► [تدقيق السجل والضريبة ZATCA] ──► [مراجعة الآيبان IBAN] ──► [اعتماد الإدارة Admin] ──► [تفعيل لوحة التحكم]
```

### 2.1 المستندات المتطلبة للقبول والاعتماد
1. **السجل التجاري الساري:** مطابقة الاسم الرسمي والنشاط التجاري لحجوزات الفعاليات أو الخدمات المساندة.
2. **الشهادة الضريبية (ZATCA):** إدخال الرقم الضريبي المكون من 15 رقماً وتدقيقه آلياً.
3. **الحساب البنكي الرسمي (IBAN):** إرفاق شهادة الآيبان الصادرة من البنك باسم الشركة/المؤسسة لمنع تحويل الأرباح لحسابات شخصية غير معتمدة.
4. **حالة الحساب بعد التدقيق:** تتحول الحالة من `Pending Approval` إلى `Approved` بقرار صريح من حساب الإدارة.

## 3. الإعدادات المالية والرقابة والسيادة الضريبية (Financial Settings & Tax Sovereign Control)

تلتزم المنصة بالضوابط المالية الصارمة والسيادة الضريبية الكاملة وفق تشريعات هيئة الزكاة والضريبة والجمارك (ZATCA).

### 3.1 القواعد والسياسات المالية السيادية
1. **تطبيق ضريبة القيمة المضافة (15% VAT):** احتساب ضريبة ليلة على عمولتها ومبيعاتها ورسومها الخاصة فقط. ضريبة المزود على حجوزاته وخدماته ومبيعاته مسؤوليته ولا تدخل حسابات ليلة، وإن أظهرت له أو للعميل فتكون مفصلة كضريبة مزود.
2. **الربط الديناميكي للعمولة:** احتساب عمولة المنصة تلقائياً فور تأكيد أي حجز `BKG` أو طلب خدمة `SRV` بناءً على باقة الشريك النشطة بدون تدخل بشري.
3. **حظر الفاتورة الضريبية الموحدة عن المزود:** تقتصر الفاتورة الموحدة على حساب الإدارة (Admin) ويُمنع إظهارها في لوحة تحكم المزود بقرار برمجيات أمني صارم.
4. **دورة تسوية الأرباح وتوزيع المستحقات:**
   - احتجاز المبالغ في حساب الضمان حتى اكتمال المناسبة بنجاح.
   - تحويل صافي مستحقات المزود بعد خصم عمولة المنصة وضريبة ليلة المستحقة عليها فقط؛ ولا تخصم ضريبة المزود لحساب ليلة عبر المعاملة المالية رقم `REV-YY-XXXXXXXXXX`.
