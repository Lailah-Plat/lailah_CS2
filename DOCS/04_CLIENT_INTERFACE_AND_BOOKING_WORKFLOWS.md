# 🛒 وثيقة واجهة العميل وتدفقات حجز القاعات والخدمات
**Client Interface Experience, Hybrid Pricing Model & End-to-End Booking Workflows**


## تحديث حاكم — سياسات الحجز والضرائب والتسعير (30-09-2026)

### أ. السياسات الأربع للحجز والدفع

تعتمد المنصة السياسات التالية: (1) **التأكيد الفوري والحجز المباشر**، وهو الافتراضي العام؛ (2) **موافقة المزود قبل الدفع**، وهو المسار الأكثر أماناً؛ (3) **الدفع المسبق قبل مراجعة المزود**؛ (4) **التفويض المسبق ثم التحصيل (Hold & Capture)**. وجود السياسة في النظام لا يمنح كل مزود حق اختيارها تلقائياً.

لمنصة ليلة القرار السيادي في تحديد السياسة العامة المسموح بها لكل نوع خدمة، ولا يجوز تجاوزها تلقائياً على مستوى كل منشأة أو منتج. إذا منحت المنصة ميزة التحكم بسياسة الحجز ضمن باقة، يصبح الإعداد لكل قاعة أو منتج أو خدمة متاحاً للمزود صاحب الاستحقاق، ضمن الخيارات التي تسمح بها المنصة وبسجل تدقيق. تحفظ لقطة غير قابلة للتغيير من السياسة الفعلية واستحقاقها وشروطها عند إنشاء الحجز.

### ب. فصل الضريبة في شاشة السعر والفاتورة

تظل ليلة مسؤولة عن ضريبة عمولتها ومبيعاتها ورسومها الخاصة. المزود مسؤول عن ضريبة حجوزاته وخدماته ومبيعاته. يجوز إظهار ضريبة المزود للمزود أو للعميل للمعاينة أو ضمن الإجمالي المعروض، مع تعريف مالك الضريبة بوضوح؛ ولا تدخل هذه الضريبة في إيرادات ليلة أو التزاماتها الضريبية، ولا تصدرها ليلة نيابة عن المزود. لذلك لا تُفسر عبارة «إجمالي الحجز + ضريبة 15%» الواردة في النص القديم على أنها ضريبة تحسبها ليلة على كامل قيمة المزود.

### ج. تثبيت السعر والتحقق عند الدفع

ينفذ الخادم احتساب السعر النهائي والتحقق من التوفر قبل التحصيل. عند تغير السعر منذ عرض السعر الأول، يُعرض الفرق للعميل ويُطلب قبوله صراحةً قبل الدفع. تحفظ في الحجز لقطة سعر مفصلة بالقواعد والإصدارات التي طبقت عليه، ولا تعيد تغييرات مستقبلية تسعير الحجز المؤكد.

هذه الإضافة تصحح التدفق المالي وسياسات الحجز، وتحافظ على بقية متطلبات واجهة البحث والخدمات والتقييمات الواردة في الوثيقة.

## 1. واجهة العميل وتجربة الاستكشاف (Client Interface & Search Engine)

توفر واجهة العميل في منصة **ليلة** تجربة استكشاف عصرية ومرنة تتيح للمستخدمين التنقل بين القاعات والأماكن والخدمات المساندة للفعاليات بنقرة واحدة.

### 1.1 مكونات واجهة العميل الرئيسية
1. **شريط البحث والتصفية المتطور:**
   - الفلترة حسب المدينة والحي.
   - الفلترة حسب السعة الاستيعابية والنطاق السعري.
   - الفلترة حسب المميزات والتجهيزات (إضاءة، مسرح، شاشات عرض، مواقف، إلخ).
2. **استعراض الوسائط العريضة:**
   - معرض صور عالي الدقة يلتزم بأسلوب العرض الشاشاتي (16:9).
   - المشغل المدمج لمقاطع الفيديو التوضيحية للقاعة (`MP4`).
3. **عرض بيانات المزود بحسب إعدادات الخصوصية:**
   - يظهر اسم المزود التجاري أو الاسم المستعار بناءً على حقل `showProviderToCustomers`.

## 2. قواعد نموذج التسعير الهجين وحظر الازدواجية (Hybrid Pricing & De-duplication Rules)

تلتزم واجهة الحجز بنموذج التسعير الهجين الذكي الذي يحمي أسبقية وأولوية مزود القاعة الأصلي ويمنع التعارض التشغيلي:

```
                           [بداية خطوات حجز القاعة]
                                     │
                                     ▼
                   ┌───────────────────────────────────┐
                   │  فحص الخدمات المضافة التابعة للقاعة │
                   └─────────────────┬─────────────────┘
                                     │
           ┌─────────────────────────┴─────────────────────────┐
           ▼                                                   ▼
┌──────────────────────────────────────┐            ┌──────────────────────────────────────┐
│  في حال توفر خدمات مضافة مدمجة بالقاعة│            │  في حال عدم توفر فئة خدمة معينة       │
│  • عرض خدمات القاعة الداخلية أولاً   │            │  • فتح خيار إضافة مزود مستقل خارجي   │
│  • حظر اقتراح مزودين مستقلين بدلاء    │            │  • الحفاظ على أولوية خدمات القاعة    │
└──────────────────────────────────────┘            └──────────────────────────────────────┘
```

### 2.1 ضوابط نموذج التسعير الهجين
1. **أولوية الخدمات الداخلية للقاعة:** إذا كان مزود القاعة المحددة يقدم خدمة إضافية مدمجة تنتمي لفئة معينة (مثل: الضيافة، التوثيق والتصوير، الصوتيات)، يُلزم النظام الواجهة بإظهار تلك الخدمات الخاصة بالقاعة فقط ضمن خطوة الخدمات المضافة.
2. **حظر تداخل الخدمات الخارجية المستقلة:** يُحظر برمجة أي اقتراح لمزودي خدمات مستقلين من نفس الفئات المتاحة مسبقاً لدى القاعة لمنع تضارب المواعيد والتعارض التشغيلي أثناء الفعالية.

## 3. خط الاستكشاف والحجز الشامل من البداية للنهاية (End-to-End Booking Flow)

```
[العميل Customer]           [واجهة منصة ليلة]           [خادم المعالجة API]           [قاعدة البيانات DB]
       │                            │                            │                            │
 1. اختيار القاعة والاريخ ─────────►│                            │                            │
       │                            │                            │                            │
 2. اختيار الخدمات المضافة ────────►│ (تطبيق قواعد عدم التكرار)  │                            │
       │                            │                            │                            │
 3. الانتقال لنافذة الدفع ─────────►│                            │                            │
       │                            │                            │                            │
 4. تاكيد الحجز والدفع ────────────►│ ─── إرسال طلب الحجز ──────►│                            │
       │                            │                            │ ─── توليد BKG-26-XXXX ────►│
       │                            │                            │ ─── توليد INV-26XXXX ────►│
       │                            │                            │ ─── احتساب العمولة ──────►│
 5. استلام سند الحجز والفاتورة ◄────┼ ─── إرجاع تفاصيل الحجز ────┤                            │
```

### 3.1 مراحل الحجز والدفع
1. **مرحلة التحديد:** اختيار تاريخ المناسبة، نوع الفعالية، وعدد الضيوف المتوقع.
2. **مرحلة الخدمات المضافة (Addons):** تحديد الخدمات الإضافية المطلوبة المتاحة ضمن خيارات القاعة.
3. **مرحلة الحساب المالي والتفصيل:**
   - المجموع الأساسي لحجز القاعة + قيمة الخدمات المضافة.
   - عرض الضرائب كبنود منفصلة: ضريبة ليلة على إيرادها ورسومها ومبيعاتها الخاصة، وضريبة المزود ـ إن عرضت ـ كبند معلوماتي منفصل لا يدخل حسابات ليلة.
   - القيمة الإجمالية النهائية المطلوبة.
4. **التأكيد وإصدار السندات:**
   - توليد رقم الحجز `BKG-YY-XXXXXXXXXX`.
   - إصدار الفاتورة الضريبية `INV-YYXXXXXXXXXX`.
   - إرسال إشعار فوري لمزود القاعة بالطلب الوارد.

## 4. نظام التعليقات والتقييمات المعتمدة (Ratings & Reviews Module)
1. **التقييم المشروط بالحجز:** يُسمح فقط للعملاء الذين أكملوا حجزاً أو طلب خدمة مؤكداً بإضافة تقييم ومراجعة.
2. **عناصر التقييم:**
   - التقييم النجمي الشامل (من 1 إلى 5 نجوم).
   - تقييم النظافة، جودة الخدمة، والالتزام بالمواعيد.
   - كتابة التعليق والملاحظات النصية.
3. **مراجعة الإدارة:** تظهر التقييمات في لوحة تحكم الإدارة لمتابعة مؤشرات جودة الخدمات والموافقة عليها.
