# 🏛️ وثيقة واجهات العملاء الرئيسية، صفحة استكشف، الصفحات التفاعلية والأدوات
**Lailah Platform - Client Portal, Exploration & Interactive Pages Specifications**

---

## 1. الواجهة الرئيسية لمنصة ليلة (Main Home Landing View)

تُعد الواجهة الرئيسية المدخل الرئيسي الذكي لعملاء المنصة للبحث عن القاعات والأماكن والخدمات المساندة للفعاليات بنقرة واحدة.

### 1.1 المكونات والوحدات الرئيسية
1. **شريط البحث المباشر السريع (Quick Search Header):**
   - اختيار المدينة (الرياض، جدة، الدمام، مكة، المدينة، الخبر، إلخ).
   - تحديد تاريخ المناسبة عبر التقويم المدمج.
   - تحديد نوع المناسبة (زواج، خطوبة، مؤتمر، اجتماع، حفلة خاصة).
   - اختيار فئة العرض (قاعات وأماكن | خدمات مساندة).
2. **شريط الميزات السريعة وشارة الضمان:**
   - شارة "حجز مؤكد معتمد".
   - شارة "دفع آمن وفاتورة ضريبية رسمية `INV-YYXXXXXXXXXX`".
   - شارة "أقل سعر معتمد مع الضمان".
3. **أقسام العروض والباقات الأكثر طلباً:**
   - عرض القاعات الأعلى تقييماً (Top Rated Venues).
   - الباقات الموسمية المجهزة بالكامل (Seasonal All-Inclusive Packages).
   - أحدث القاعات المضافة المعتمدة حديثاً (`Approved`).

## 2. صفحة استكشف القاعات والأماكن (Venues Exploration Page)

صفحة استكشاف تفاعلية تتيح للعملاء البحث المتقدم والتصفية الدقيقة لجميع القاعات المعتمدة بالمنصة.

### 2.1 محرك التصفية المتقدم (Advanced Filter Engine)
- **التصفية الجغرافية:** حسب المدينة، الحي، وإظهار القاعات القريبة.
- **التصفية بالسعة والسعر:**
  - شريط النطاق السعري لليوم/الفترة (السعر الأدنى إلى الأقصى).
  - نطاق عدد الضيوف السعة الاستيعابية (مثال: 50 - 1000 شخص).
- **التصفية بالتجهيزات والمميزات:**
  - قاعات رجال / قاعات نساء / جناح للعروس / جناح لكبار الشخصيات.
  - إضاءة وشاشات عرض LED / أنظمة صوتية ومتحدثين.
  - مواقف سيارات خاصة / خدمة إيقاف السيارات.
  - بوفيه مفتوح ومطبخ خارجي.

## 3. صفحة تفاصيل القاعة المباشرة (Hall Details Page)

صفحة العرض التفاعلية الشاملة لكافة تفاصيل ومعلومات القاعة المختارة.

### 3.1 أقسام صفحة القاعة
1. **معرض الوسائط العريض (Wide Media Gallery):**
   - استعراض الصور بأسلوب 16:9 مع خيار التكبير، والتزام الصور بحجم أقصاه `500KB` وأبعاد بين `960x540` و `1280x720` بكسل.
   - مشغل مقطع الفيديو التوضيحي المدمج (`MP4` بحد أقصى `10MB`).
2. **بيانات ومعلومات القاعة الأساسية:**
   - اسم القاعة، السعة القصوى، الموقع والحي.
   - اسم المزود المعتمد أو الاسم المستعار بناءً على إعداد `showProviderToCustomers`.
3. **جدول المميزات والتجهيزات:**
   - استعراض الأقسام والتجهيزات المتاحة بالقاعة.
4. **قسم الخدمات المضافة المدمجة بالقاعة (Hall Integrated Addons):**
   - **تطبيق قاعدة نموذج التسعير الهجين:** عرض جميع الخدمات الإضافية التابعة لمزود القاعة الأصلي (ضيافة، توثيق وتصوير، إضاءة، ديكور) مع أسعارها المعتمدة وحظر الموردين المستقلين المكررين بنفس الفئة.
5. **التقويم اللحظي للتواريخ المتاحة والمحجوزة:**
   - عرض الأيام الشاغرة بوضوح لمنع تضارب الحجوزات.
6. **زر التفاعلات السريعة:**
   - إضافة إلى القاعات المفضلة ❤️.
   - مشاركة القاعة عبر شبكات التواصل 🔗.
   - بدء المحادثة المباشرة مع المزود 💬.
   - زر "احجز الآن" للانتقال لنافذة الحجز المباشر.

## 4. صفحة الخريطة التفاعلية (Interactive Venues Map Page)

صفحة خريطة تفاعلية كاملة تمكّن العملاء من استكشاف مواقع القاعات والمنشآت جغرافياً بشكل حي.

### 4.1 الميزات الوظيفية للخريطة
- **دبابيس الموقع الجغرافي (Map Pins):** إظهار مواقع القاعات المعتمدة على الخريطة.
- **بطاقة المعاينة السريعة (Quick Preview Card):** عند النقر على دبوس القاعة، تظهر بطاقة مصغرة تحتوي صورة القاعة، السعر، السعة، والتقييم، مع زر للانتقال السريع لصفحة التفاصيل.
- **إعادة البحث عند تحريك الخريطة:** إعادة جلب القاعات المتاحة فور تغيير النطاق الجغرافي بالخريطة.

## 5. صفحة حاسبة الميزانية الذكية (Smart Budget Calculator Page)

أداة تفاعلية تساعد العملاء على تخطيط ميزانية المناسبة وتوزيع التكاليف بشكل تقديري دقيق.

### 5.1 آلية عمل حاسبة الميزانية
1. **إدخال الميزانية الكلية المرصودة:** (مثال: 50,000 ريال سعودي).
2. **تحديد نوع المناسبة وعدد الضيوف المتوقع.**
3. **التوزيع التلقائي الذكي للميزانية:**
   - حجز القاعة والمكان (حوالي 50% - 60%).
   - الضيافة والبوفيه المفتوح (20% - 25%).
   - التوثيق والتصوير والوسائط (10%).
   - الإضاءة والديكور والصوتيات (10%).
4. **اقتراح القاعات والخدمات المناسبة للميزانية:** إظهار قائمة القاعات المعتمدة التي تطابق النطاق المالي المقترح.

## 6. صفحة العروض والباقات الشاملة (Offers & Inclusive Packages Page)

صفحة متخصصة لعرض الحزم والباقات الجاهزة والمخفّضة للمناسبات.

### 6.1 أنواع الباقات والعروض
- **باقات الزواجات الشاملة (All-Inclusive Wedding Packages):** حجز القاعة + الضيافة + التصوير + الإضاءة بسعر خصم موحد.
- **عروض الأيام المحددة (Mid-week Special Offers):** خصومات حصرية لحجوزات أيام منتصف الأسبوع.
- **كوبونات الخصم والترويج:** تطبيق القسائم وتفعيل الخصم المباشر بالفاتورة.

## 7. صفحة التقويم الذكي للحجوزات (Smart Availability Calendar Page)

صفحة مركزية تتيح للعملاء استعراض تواريخ توفر القاعات على مستوى الشهور والأيام.

### 7.1 الخصائص والوظائف
- **تصفية التواريخ حسب المدينة ونوع القاعة.**
- **التلوين البصري الذكي:**
  - اللون الأخضر: أيام متاحة وشاغرة للحجز المباشر.
  - اللون الأحمر: أيام محجوزة ومؤكدة مؤخراً برقم حجز `BKG-YY-XXXXXXXXXX`.
  - اللون الأصفر: تواريخ قيد الانتظار أو الصيانة.

## 8. صفحتا "من نحن" و "اتصل بنا" (About Us & Contact Us Pages)

### 8.1 صفحة من نحن (About Us)
- التعريف بمنصة "ليلة" بصفتها المنظومة الوطنية المعتمدة لحجوزات الفعاليات بالمملكة.
- الرؤية، الرسالة، والقيم الجوهرية (الأمان، الشفافية، الجودة، وسرعة الخدمة).

### 8.2 صفحة اتصل بنا (Contact Us)
- **نموذج التواصل المباشر:** الاسم، البريد، رقم الجوال، عنوان الرسالة، ونوع الاستفسار.
- **بيانات التواصل الرسمية:** البريد المعتمد، الرقم الموحد، السجل التجاري، والعنوان التجاري بمقر الشركة.
- **روابط الدعم الفني وتذاكر الدعم المباشرة.**
