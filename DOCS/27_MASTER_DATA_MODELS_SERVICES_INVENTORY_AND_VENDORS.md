# 🛠️ وثيقة النماذج المعيارية لبيانات الخدمات والمخزون والموردين المتعاقدين
**Master Entity Data Models: Auxiliary Services, Venue Inventory Items & External Vendors**

---

## 1. نموذج بيانات الخدمات المساندة (Auxiliary Services Master Data Entity)

يُغطي هذا النموذج كافة البيانات الهيكلية والتسعيرية للخدمات المساندة سواء كانت خدمات إضافية مدمجة تابعة لمزود القاعة الأصلي أو خدمات مساندة مستقلة يُقدمها موردون خارجيون بالمنصة.

```
                  ┌───────────────────────────────────────────┐
                  │   نموذج بيانات الخدمات (Service Entity)   │
                  └─────────────────────┬─────────────────────┘
                                        │
     ┌──────────────────────┬───────────┴───────────┬──────────────────────┐
     ▼                      ▼                       ▼                      ▼
┌─────────┐            ┌─────────┐             ┌─────────┐            ┌─────────┐
│ الفئة   │            │ نوع     │             │ التسعير │            │ حالة    │
│ والنوع  │            │ الخدمة  │             │ والشروط │            │ الاعتماد│
└─────────┘            └─────────┘             └─────────┘            └─────────┘
```

### 1.1 جدول الحقول والمواصفات البرمجية لبيانات الخدمة

| الحقل البرمجي (Field Name) | النوع (Data Type) | القيود والافتراضات | الشرح والتفاصيل التشغيلية |
| :--- | :--- | :--- | :--- |
| `serviceId` | `String` | فريد، إجباري (Primary Key) | المعرف الفريد السحابي للخدمة المساندة. |
| `providerId` | `String` | مفتاح أجنبي (Foreign Key) | المعرف الفريد للشريك المالك للخدمة (لفرض العزل البرمجي بحسب `providerId`). |
| `hallId` | `String` | اختياري (Foreign Key) | معرف القاعة المرتبطة بالخدمة في حال كانت "خدمة مدمجة بالقاعة" (Integrated Addon). |
| `serviceCategory` | `Enum` | `'catering'` \| `'photography'` \| `'lighting_sound'` \| `'decor'` \| `'valet_cars'` | الفئة الرئيسية للخدمة (ضيافة، تصوير، إضاءة وصوت، ديكور، سيارات وفاليه). |
| `serviceType` | `Enum` | `'hall_integrated_addon'` \| `'independent_service'` | نوع الخدمة: خيار مدمج بالقاعة أو خدمة مستقلة بالمتجر. |
| `title` | `String` | إجباري، 3-100 حرف | عنوان الخدمة المعروض بالمتجر (مثال: بوفيه فاخر 200 شخص، تصوير فيديو سينمائي). |
| `price` | `Number` | إجباري، أكبر من 0 | سعر الخدمة المعتمد شامل الخيارات والتوريد الميداني. |
| `approvalStatus` | `Enum` | `'pending'` \| `'approved'` \| `'rejected'` | حالة اعتماد الخدمة المستقلة من الإدارة العامة (`Pending Approval` افتراضياً). |

## 2. قواعد نموذج التسعير الهجين ومنع ازدواجية الخدمات (Hybrid Pricing & Service De-duplication)

تُطبق القاعدة التالية بشكل صارم في واجهة الحجز ونظام اقتراح الخدمات الإضافية (Addons):

```
[حجز قاعة معينة BKG] ──► [فحص الخدمات المضافة المدمجة بالقاعة]
                                  │
       ┌──────────────────────────┴──────────────────────────┐
       ▼                                                     ▼
(تتوفر خدمة في فئة معينة بالمرتبطة بالقاعة)         (لا تتوفر خدمة بتلك الفئة بالقاعة)
       │                                                     │
       ▼                                                     ▼
[حظر الموردين الخارجيين المستقلين من نفس الفئة]      [إتاحة اقتراح الموردين المستقلين الخارجيين]
```

1. **حظر تداخل الخدمات الخارجية مع خدمات المكان:** إذا كان مزود القاعة المعنية يقدم خدمة إضافية تندرج تحت فئة معينة (مثل: الضيافة، التوثيق والتصوير، الإضاءة)، يُحظر نهائياً عرض أو اقتراح أي مزودي خدمات خارجيين مستقلين من نفس الفئة أثناء الحجز.
2. **أولوية خدمات القاعة الداخلية:** إعطاء الأولوية التامة لخدمات مزود القاعة الأصلي لضمان أولوية البيع وتفادي التعارض التشغيلي الميداني.

## 3. نموذج بيانات الأصناف وأفراد المخزون بالقاعات (Venue Inventory Item Master Entity)

يُغطي هذا النموذج تتبع الأثاث، المعدات والأجهزة والمستلزمات الفيزيائية المتاحة داخل القاعات والصالات.

```
+-----------------------------------------------------------------------------------+
|                     Hall Physical Inventory Item Entity Structure                 |
+-----------------------------------------------------------------------------------+
|  • Identifiers: itemId, hallId, providerId, barcode/serialNumber                   |
|  • Item Details: itemName, category ('furniture' | 'catering_tools' | 'av_gear')  |
|  • Stock Quantities: totalQuantity, availableQuantity, inMaintenanceQuantity     |
|  • Safety Level: minimumThreshold (تنبيه إعادة التزويد Safety Stock Alert)       |
|  • Valuation: unitCost, totalValuation, depreciationRate                         |
+-----------------------------------------------------------------------------------+
```

### 3.1 جدول حقول الأصناف والمخزون بالقاعة

| الحقل البرمجي (Field Name) | النوع (Data Type) | القيود | الشرح والوظيفة |
| :--- | :--- | :--- | :--- |
| `itemId` | `String` | فريد (Primary Key) | المعرف الفريد لصنف المخزون بالقاعة. |
| `hallId` / `providerId` | `String` | مفاتيح أجنبية | الربط بالقاعة والمزود المالك لفرض عزل البيانات. |
| `itemName` | `String` | 3-80 حرف | اسم الصنف المادي (مثل: كراسي نابليون ذهبية، طاولات دائرية، سماعات صوتية). |
| `category` | `Enum` | `'furniture'` \| `'catering_tools'` \| `'av_gear'` \| `'decor'` | فئة صنف المخزون (أثاث، أدوات ضيافة، معدات صوت وضوء، ديكورات). |
| `totalQuantity` | `Number` | أكبر من أو يساوي 0 | العدد الكلي المسجل من الصنف بالمخزون. |
| `availableQuantity` | `Number` | أقل من أو يساوي Total | الكمية المتاحة وجاهزة للاستخدام بالمناسبات الحالية. |
| `minimumThreshold` | `Number` | إجباري | حد الأمان الأدنى لإطلاق تنبيه إعادة التزويد أو الصيانة آلياً. |

## 4. نموذج بيانات الموردين الخارجيين والمتعاقدين (External Vendor Master Entity)

يُغطي هذا النموذج بيانات المؤسسات والمتعهدات الخارجية التي يتعاقد معها مزود القاعة لتنفيذ التجهيزات والخدمات الميدانية.

| الحقل البرمجي (Field Name) | النوع (Data Type) | القيود والاشتراطات | الشرح والوظيفة |
| :--- | :--- | :--- | :--- |
| `vendorId` | `String` | فريد (Primary Key) | المعرف الفريد للمورد الخارجي في قاعدة البيانات. |
| `providerId` | `String` | مفتاح أجنبي | المزود المتعاقد مع هذا المورد المباشر. |
| `companyName` | `String` | إجباري | اسم شركة أو مؤسسة التوريد الخارجية. |
| `crNumber` / `phone` | `String` | إجباري | رقم السجل التجاري وجوال التواصل مع المورد. |
| `suppliedCategory` | `Enum` | `'catering_supply'` \| `'flowers'` \| `'security'` \| `'av_equipment'` | الفئة اللوجستية التي يوردها (ذبائح، زهور، حراسات أمنية، تجهيزات صوت). |
| `contractStatus` | `Enum` | `'active'` \| `'expired'` \| `'suspended'` | حالة العقد التجاري والتنفيذي مع القاعة. |

## 5. الربط المالي والتسلسلي الموحد

- **طلبات الخدمات المساندة:** تُصدر وتوثق برقم طلب قياسي `SRV-YY-XXXXXXXXXX` (مثل: `SRV-26-0000000001`).
- **الفاتورة الضريبية الصادرة:** `INV-YYXXXXXXXXXX` (مثل: `INV-260000000001`).
- **تسويات المصروفات الميدانية:** `EXP-YY-XXXXXXXXXX` (مثل: `EXP-26-0000000001`).
