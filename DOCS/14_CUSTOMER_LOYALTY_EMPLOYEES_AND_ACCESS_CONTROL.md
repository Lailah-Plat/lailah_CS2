# 👥 وثيقة إدارة العملاء، برنامج الولاء، الموظفين وإدارة الصلاحيات
**Customer Management, Loyalty Engine, Corporate Staff & Access Control Governance (RBAC)**

---

## 1. وحدة إدارة العملاء وبرنامج الولاء (Customer Management & Loyalty Engine)

تُقدم منصة **ليلة** محركاً متكاملاً لإدارة علاقات العملاء (CRM) وبرنامج نقاط الولاء الكافية لتعزيز الاحتفاظ بالعملاء وزيادة الحجوزات التكرارية.

```
                  ┌───────────────────────────────────────────┐
                  │    محرك برنامج الولاء (Lailah Loyalty)    │
                  └─────────────────────┬─────────────────────┘
                                        │
           ┌────────────────────────────┴────────────────────────────┐
           ▼                                                         ▼
┌──────────────────────────────────────┐  ┌──────────────────────────────────────┐
│       مستويات ولاء العميل (Tiers)    │  │       اكتساب واستبدال النقاط         │
│   • الفضية (Silver) - المبتدئ         │  │   • 1 نقطة لكل 100 ريال مصنفة      │
│   • الذهبية (Gold) - المتقدم         │  │   • خصومات مباشرة على الحجوزات       │
│   • الماسيه (Diamond) - النخبة       │  │   • ترقية للخدمات الإضافية          │
└──────────────────────────────────────┘  └──────────────────────────────────────┘
```

### 1.1 معايير مستويات الولاء (Customer Loyalty Tiers)
1. **المستوى الفضي (Silver Tier):**
   - **الشرط:** عند التسجيل وإنشاء الحساب.
   - **المميزات:** اكتساب نقاط أساسية (1 نقطة لكل 100 ريال)، وأسبقية الدعم الفني.
2. **المستوى الذهبي (Gold Tier):**
   - **الشرط:** إكمال حجوزات بقيمة 20,000 ريال أو 3 حجوزات ناجحة خلال العام.
   - **المميزات:** مضاعفة النقاط (1.5x)، خصم 5% على الخدمات المضافة، وإمكانية الإلغاء المرن.
3. **المستوى الماسي (Diamond Tier):**
   - **الشرط:** إكمال حجوزات بقيمة 50,000 ريال أو 6 حجوزات ناجحة خلال العام.
   - **المميزات:** مضاعفة النقاط (2x)، خصم 10% على الخدمات المضافة، ومدير حساب خاص للدعم المباشر.

### 1.2 سجل العملاء والتحليلات (Customer CRM Records)
- استعراض الملف الشخصي للعميل، السجل التاريخي للحجوزات برقم `BKG-YY-XXXXXXXXXX` والطلبات `SRV-YY-XXXXXXXXXX`.
- الفواتير الصادرة `INV-YYXXXXXXXXXX` ورصيد النقاط الحالي والتقييمات المقدمة منه.

## 2. إدارة الموظفين والصلاحيات والرقابة البرمجية (Corporate Employees & RBAC Governance)

تعتمد منصة "ليلة" على نظام إدارة الصلاحيات القائم على الأدوار (Role-Based Access Control - RBAC) للتحكم الدقيق في الوصول للمخرجات والبيانات سواء على مستوى الإدارة أو الشركات المزودة.

```
+-----------------------------------------------------------------------------------+
|                        Lailah Role-Based Access Control (RBAC)                    |
+-----------------------------------------------------------------------------------+
|  [👑 المدير العام Admin]   [💼 المدير المالي Finance]   [🎧 مشرف الدعم Support]   |
|  [🏛️ مدير الأصول Asset]    [👨‍💼 الشريك/المزود Provider]  [👷 الموظف الميداني Staff]  |
+-----------------------------------------------------------------------------------+
```

### 2.1 هيكلية الأدوار والصلاحيات المعتمدة (Role Permission Matrix)

| اسم الدور (Role) | الصلاحيات والمهام المسموحة | الحدود الأمنية والقيود |
| :--- | :--- | :--- |
| **المدير العام (Super Admin)** | وصول مطلق لجميع الشاشات، الاعتمادات، المالية، والإعدادات. | لا توجد قيود. |
| **المدير المالي (Finance Officer)** | استعراض الفواتير الموحدة `INV`، تقارير الإيرادات `REV` والعمولات. | حظر تعديل بيانات القاعات أو حذف الحسابات. |
| **مسؤول اعتماد الأصول (Asset Approver)** | مراجعة واعتماد القاعات والخدمات المعلقة (`Pending`). | حظر الوصول للبيانات المالية السيادية. |
| **مشرف الدعم الفني (Support Agent)** | معالجة تذاكر الدعم والرسائل المباشرة والشكاوى. | حظر تعديل العمولات أو تفاصيل العقود. |
| **مزود الخدمة (Provider Master)** | إدارة قاعاته وخدماته وحجوزاته وماليته الخاصة بـ `providerId`. | حظر الإعدادات العامة والفاتورة الضريبية الموحدة. |
| **موظف التشغيل لدى المزود (Provider Staff)** | متابعة التقويم التشغيلي، تحديث حالة الحجز والطلبات. | حظر استعراض التقارير المالية والتحويلات البنكية للمزود. |

### 2.2 سجل المراجعة والتتبع الأمني (Security Audit Log)
- تسجيل كل إجراء حساس بالمنظومة (مثل: تغيير حالة الاعتماد، تعديل العمولة، صرف مستحقات، أو تعديل صلاحية) متضمناً:
  - معرف الموظف القائم بالإجراء.
  - عنوان IP والجلسة المعتمدة.
  - التاريخ والوقت بدقة وتفاصيل البيانات القبلية والبعدية.
