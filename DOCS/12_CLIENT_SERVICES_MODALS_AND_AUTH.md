# 🛠️ وثيقة صفحة الخدمات والنوافذ المنبثقة وتسجيل الدخول وإنشاء الحساب
**Lailah Platform - Services View, Interactive Modals & Authentication Engine**


## تحديث حاكم — قرار المصادقة النهائي (30-09-2026)

القرار الأحدث بتاريخ 24-09-2026 هو المرجع. يسجل العميل عبر النموذج أو موفري Apple/Google الاختياريين، ويسجل المزود ببياناته ومستنداته. الدخول بالبريد أو رقم الجوال مع كلمة مرور. يستخدم OTP للتحقق من البريد أو رقم الجوال ولإعادة تعيين كلمة المرور، مع حد يومي للمحاولات/الرسائل. يجب توثيق رقم الجوال لجميع الأدوار.

تمنع كلمة المرور المسافات وتشترط حرفاً كبيراً وحرفاً صغيراً ورقماً ورمزاً. يخزن التحقق بكلمة مرور باستخدام خوارزمية مخصصة آمنة مثل bcrypt/Argon2، ولا يستخدم SHA-256 منفرداً لتخزين كلمات المرور. أي وصف أقدم للدخول برمز OTP وحده مستبدل بهذا القرار. لا يجوز تعطيل إعداد التكامل مع OTP بما يسمح بتجاوز شرط توثيق الجوال؛ يمكن فصل تعطل قناة الإرسال عن إثبات التوثيق عبر مسار استعادة/تحقق آمن.

### فصل الضرائب المعروضة

ضريبة المزود عند طلب الخدمة أو حجز القاعة تظل التزاماً على المزود. قد تظهر للعميل ضمن عرض الإجمالي، لكنها تُعرّف كضريبة المزود وتبقى خارج دفاتر ليلة. ضريبة ليلة تحسب فقط على إيرادها ورسومها ومبيعاتها.

## 1. صفحة الخدمات المساندة المستقلة (Independent Services View)

صفحة متخصصة لعرض جميع الخدمات المساندة المتاحة بالمنصة بشكل مستقل عن حجز القاعات.

### 1.1 أقسام وفئات الخدمات
1. **تصنيف الفئات الرئيسية:**
   - **الضيافة والفندقة:** بوفيهات مفتوحة، صبابين وقهوجية، ذبائح ومشروبات.
   - **التوثيق والتصوير:** تصوير فوتوغرافي، تصوير فيديو سينمائي، طائرات درون.
   - **الإضاءة والصوتيات:** أنظمة الصوت، دي جي، كشافات الممر، الليزر والمهندسين.
   - **الديكور والتنسيق:** كوشة العروس، تنسيق الزهور، الطاولات والكراسي.
   - **السيارات والضيافة:** سيارات زفاف فاخرة، خدمة إيقاف السيارات (Valet).
2. **شريط التصفية والبحث في الخدمات:**
   - التصفية حسب المدينة، الفئة، والنطاق السعري.

## 2. نافذة تفاصيل الخدمة المساندة (Service Details Modal)

نافذة منبثقة تظهر عند اختيار خدمة مساندة محددة لاستعراض كامل تفاصيلها قبل الطلب.

### 2.1 محتويات نافذة تفاصيل الخدمة
- **معرض صور الخدمة:** استعراض صور العمل السابقة والجودة عالية الدقة.
- **تفاصيل الباقة والمحتويات:** شرح ما تشتمل عليه الخدمة وساعات العمل.
- **سعر الخدمة والتفاصيل المالية:** السعر الأساسي شامل الخيارات.
- **معلومات مزود الخدمة:** اسم المزود التجاري أو الاسم المستعار بناءً على حقل الخصوصية `showProviderToCustomers`.
- **زر الطلب المباشر:** الانتقال لنافذة "طلب خدمة مساندة".

---

## 3. نافذة طلب خدمة مساندة (Request Service Modal)

النافذة المخصصة لإتمام طلب خدمة مساندة وتأكيد بيانات التنفيذ.

### 3.1 مراحل وتدفق طلب الخدمة
1. **إدخال تفاصيل المناسبة:**
   - تاريخ التقديم والتنفيذ المباشر.
   - موقع المناسبة (المدينة، الحي، أو تحديد موقع القاعة).
   - الملاحظات والمتطلبات الخاصة بالخدمة.
2. **الملخص المالي والتسلسلي:**
   - توليد رقم طلب الخدمة القياسي `SRV-YY-XXXXXXXXXX` (مثال: `SRV-26-0000000001`).
   - عرض المبالغ والضرائب مفصلة بحسب مالكها؛ ضريبة المزود مسؤوليته ولا تدخل حسابات ليلة، ويمكن إظهارها للمعاينة كبند منفصل.
   - توليد رقم الفاتورة `INV-YYXXXXXXXXXX`.
   - اقتطاع عمولة المنصة المحددة آلياً بمركز المالية.
3. **التأكيد والدفع:** خيارات المدى، الفيزا/الماستركارد، أو Apple Pay.

## 4. نافذة حجز القاعة المباشر (Venue Booking Modal)

النافذة المركزية لتأكيد حجز القاعة واختيار الخدمات المضافة وتأكيد الدفع.

```
                           [نافذة حجز القاعة المباشر]
                                      │
 ┌────────────────────────────────────┼────────────────────────────────────┐
 │  1. اختيار التاريخ وعدد الضيوف      │   2. تحديد الخدمات المضافة         │
 └────────────────────────────────────┼────────────────────────────────────┘
                                      │
 ┌────────────────────────────────────┼────────────────────────────────────┐
 │  3. ملخص الفاتورة BKG و INV        │   4. اختيار وسيلة الدفع والتأكيد   │
 └────────────────────────────────────┴────────────────────────────────────┘
```

### 4.1 خطوات نافذة حجز القاعة
1. **تحديد الفترة وتاريخ المناسبة:** التأكد اللحظي من توفر القاعة.
2. **اختيار الخدمات المضافة التابعة للقاعة:** تطبيق قاعدة نموذج التسعير الهجين وحظر خدمات المزودين الخارجيين المكررين بنفس الفئة.
3. **توليد الرقم التسلسلي والحساب المالي:**
   - رقم الحجز `BKG-YY-XXXXXXXXXX`.
   - رقم الفاتورة الصادرة `INV-YYXXXXXXXXXX`.
   - قيمة الحجز والخدمات المضافة، مع فصل ضريبة ليلة عن ضريبة المزود وإظهار مالك كل بند.
   - حساب صافي مستحقات المزود وعمولة المنصة آلياً.
4. **تأكيد الحجز وإرسال التنبيهات اللحظية.**

## 5. محرك تسجيل الدخول وإنشاء حساب جديد (Authentication & Account Creation Engine)

تسمح المنظومة بإنشاء وتسجيل الحسابات بمرونة وأمان كامل وفق صلاحيات الأدوار المحددة.

### 5.1 نافذة تسجيل الدخول (Sign In Modal / View)
- **خيارات تسجيل الدخول:**
  - تسجيل الدخول بالبريد الإلكتروني أو رقم الجوال مع كلمة المرور.
  - يستخدم OTP للتحقق من البريد/الجوال واستعادة كلمة المرور؛ لا يحل OTP وحده محل كلمة المرور في مسار الدخول المعتمد.
- **تحديد دور المستخدم تلقائياً:** التوجيه الآلي بعد الدخول (عميل ➔ متجر العملاء | مزود ➔ Provider Workspace ERP | إدارة ➔ Admin Dashboard).

### 5.2 نافذة إنشاء حساب جديد (Registration / Sign Up)
1. **اختيار نوع الحساب:**
   - **حساب عميل (Customer Account):** الاسم الثلاثي، البريد، الجوال، وكلمة المرور.
   - **حساب مزود خدمة / شريك (Provider Account):**
     - الاسم التجاري الرسمي للمنشأة.
     - البريد الرسمي ورقم الجوال.
     - السجل التجاري ورقم الرخصة.
     - الرقم الضريبي للهيئة العامة للزكاة والدخل (ZATCA).
     - الحساب البنكي الرسمي (اسم البنك + رقم الآيبان IBAN).
     - اختيار حقل الخصوصية `showProviderToCustomers` وإدخال اسم المستخدم/الاسم المستعار للعملاء (اختياري).
2. **التحقق والتفعيل:** تأكيد الحساب وتوجيه المزود لمعالج التهيئة الأولية.
