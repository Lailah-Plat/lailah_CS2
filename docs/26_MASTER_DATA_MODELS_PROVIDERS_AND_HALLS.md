# 🏢 وثيقة النماذج المعيارية لبيانات المزودين والقاعات والأصول والوسائط
**Master Entity Data Models: Providers, Venues/Halls, Assets & Media Specifications**

---

## 1. نموذج بيانات المزود / الشريك (Provider Master Data Entity)

يُغطي هذا النموذج كافة البيانات الهيكلية والقانونية والمالية والإدارية المتعلقة بالشركاء ومزودي القاعات والخدمات المساندة في منصة **ليلة**.

```
+-----------------------------------------------------------------------------------+
|                        Provider Master Entity Structure                           |
+-----------------------------------------------------------------------------------+
|  • Identifiers: providerId, dbId, uuid, registrationYear                          |
|  • Official Info: legalName, tradeName, crNumber, taxNumber (ZATCA 15-digit)       |
|  • Banking Info: bankName, iban, accountHolderName, verifiedStatus                |
|  • Subscription: tier ('basic' | 'advanced' | 'pro'), commissionRate (15%/10%/7%)|
|  • Privacy & Display: showProviderToCustomers (boolean), customerAlias/username   |
|  • Governance: approvalStatus ('pending' | 'approved' | 'suspended')               |
+-----------------------------------------------------------------------------------+
```

### 1.1 جدول الحقول والمواصفات البرمجية لبيانات المزود

| الحقل البرمجي (Field Name) | النوع (Data Type) | الاشتراطات والقيود (Constraints) | الشرح والتفاصيل |
| :--- | :--- | :--- | :--- |
| `providerId` | `String` | فريد، إجباري (Primary Key) | المعرف الفريد السحابي للمزود في النظام. |
| `legalName` | `String` | إجباري، 3-100 حرف | الاسم التجاري الرسمي المسجل في السجل التجاري. |
| `tradeName` | `String` | اختياري | الاسم التسويقي للمنشأة أو العلامة التجارية. |
| `crNumber` | `String` | فريد، 10 أرقام | رقم السجل التجاري المعتمد لدى وزارة التجارة. |
| `taxNumber` | `String` | فريد، 15 رقم | الرقم الضريبي الرسمي الصادر عن هيئة الزكاة والضريبة والجمارك (ZATCA). |
| `bankName` | `String` | إجباري | اسم البنك المحلي المعتمد للحساب التجاري. |
| `iban` | `String` | فريد، يبدأ بـ SA (24 خانة) | رقم الحساب البنكي الدولي الرسمي المعتمد لصرف المستحقات والتحويلات المالية `REV-YY-XXXXXXXXXX`. |
| `subscriptionTier` | `Enum` | `'basic'` \| `'advanced'` \| `'pro'` | باقة الاشتراك النشطة للشركاء والمرتبطة بنسبة اقتطاع عمولة المنصة آلياً. |
| `commissionRate` | `Number` | **15%** (Basic) \| **10%** (Advanced) \| **7%** (Pro) | نسبة عمولة المنصة المقتطعة آلياً من الحجوزات والخدمات الناجحة. |
| `showProviderToCustomers` | `Boolean` | افتراضي: `true` | خيار التحكم بإظهار اسم المنشأة الرسمي للعملاء في متجر المنصة. |
| `customerAlias` | `String` | اختياري | الاسم المستعار/اسم المستخدم المعروض للعملاء في حال إلغاء تفعيل إظهار الاسم التجاري الرسمي. |
| `approvalStatus` | `Enum` | `'pending'` \| `'approved'` \| `'suspended'` | حالة اعتماد الشريك من قبل الإدارة العامة (Admin) قبل السماح بالتشغيل. |

## 2. نموذج بيانات القاعات والأماكن (Venue / Hall Master Data Entity)

يُمثل هذا النموذج البيانات التشغيلية والهندسية والجغرافية للقاعات والصالات والمرافق التابعة للشركاء.

```
                  ┌───────────────────────────────────────────┐
                  │    نموذج بيانات القاعات (Hall Entity)     │
                  └─────────────────────┬─────────────────────┘
                                        │
     ┌──────────────────────┬───────────┴───────────┬──────────────────────┐
     ▼                      ▼                       ▼                      ▼
┌─────────┐            ┌─────────┐             ┌─────────┐            ┌─────────┐
│ البيانات│            │ السعة   │             │ التجهيز │            │ الوسائط │
│ الأساسية│            │ والأسعار│             │ والمرافق│            │ المعتمدة│
└─────────┘            └─────────┘             └─────────┘            └─────────┘
```

### 2.1 جدول الحقول والمواصفات البرمجية لبيانات القاعة

| الحقل البرمجي (Field Name) | النوع (Data Type) | القيود والمعايير | الشرح والوظيفة التشغيلية |
| :--- | :--- | :--- | :--- |
| `hallId` | `String` | فريد، إجباري (Primary Key) | المعرف الفريد السحابي للقاعة. |
| `providerId` | `String` | مفتاح أجنبي (Foreign Key) | المعرف الفريد للمزود المالك للقاعة (لفرض العزل البرمجي الصارم). |
| `hallName` | `String` | إجباري، 3-80 حرف | الاسم التجاري للقاعة أو الصالة المعروض بمتجر العملاء. |
| `city` / `district` | `String` | إجباري | المدينة والحي الجغرافي الواقعة به القاعة (الرياض، جدة، الدمام...). |
| `locationCoordinates` | `Object` | `{ lat: Number, lng: Number }` | الإحداثيات الجغرافية الدقيقة لعرض القاعة على الخريطة التفاعلية. |
| `capacity` | `Object` | `{ min: Number, max: Number }` | السعة الاستيعابية الأدنى والقصوى لعدد الضيوف والحضور. |
| `basePricePerDay` | `Number` | إجباري، أكبر من 0 | السعر الأساسي لحجز القاعة لليوم/الفترة الواحدة شامل تجهيزات القاعة. |
| `peakPriceAdjustment` | `Number` | نسبة % أو مبلغ ثابت | زيادة السعر المعتمدة لمواسم الذروة وعطلات نهاية الأسبوع وفق ضوابط حوكمة الإدارة. |
| `amenities` | `Array<String>` | قائمة نصية | التجهيزات المتاحة (قاعة نساء، جناح عروس، إضاءة LED، صوتيات، بوفيه، فاليه). |
| `approvalState` | `Enum` | `'pending'` \| `'approved'` \| `'rejected'` | حالة اعتماد القاعة من الإدارة (`Pending Approval` افتراضياً حتى الموافقة الرسمية). |

## 3. مواصفات وسائط القاعات والخدمات (Media Specifications Engine)

يُطبق النظام قواعد صلبة لتدقيق الوسائط المرفوعة لكل قاعة لضمان الجودة الأداء والسلاسة:

```
+-----------------------------------------------------------------------------------+
|                       Strict Media Validation Specifications                      |
+-----------------------------------------------------------------------------------+
|  [🖼️ الصور Images]                                                               |
|  • Formats: JPEG, JPG, PNG, WebP                                                  |
|  • Max File Size: 500KB (رفض آلي لأي ملف يتجاوز 500KB)                          |
|  • Min Dimensions: 960px x 540px                                                  |
|  • Max Dimensions: 1280px x 720px                                                 |
|  • Preferred Aspect Ratio: 16:9 (عريضة)                                           |
|                                                                                   |
|  [🎥 الفيديوهات Videos]                                                           |
|  • Format: MP4 (صيغة MP4 القياسية فقط)                                            |
|  • Max File Size: 10MB (رفض آلي لأي ملف يتجاوز 10MB)                              |
|  • Max Dimensions: 960px x 540px (دقة QHD بنسبة 16:9)                            |
+-----------------------------------------------------------------------------------+
```

## 4. تدفق حوكمة العزل البرمجي والربط المالي للقاعات

1. **الربط بالمعرفات التسلسلية القياسية (بداية كل عام ميلادي من `0000000001`):**
   - **حجوزات القاعة:** `BKG-YY-XXXXXXXXXX` (مثال: `BKG-26-0000000001`).
   - **الفواتير الضريبية الصادرة:** `INV-YYXXXXXXXXXX` (مثال: `INV-260000000001` بدون واصلة بعد السنة).
   - **تسويات الإيرادات:** `REV-YY-XXXXXXXXXX` (مثال: `REV-26-0000000001`).
2. **السيادة والرقابة الضريبية:**
   - احتساب ضريبة 15% ZATCA بالفواتير الصادرة الموحدة.
   - حظر الفاتورة الموحدة والإعدادات العامة عن لوحة الشريك واقتصارها على إدارة المنصة (Super Admin).
