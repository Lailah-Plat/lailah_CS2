# وثيقة تدفقات العمليات والنموذج المالي الهجين - منصة ليلة

## 1. نموذج التسعير الهجين وحظر الازدواجية (Hybrid Pricing & De-duplication Engine)

لتوفير تجربة حجز سلسة وضمان حقوق الشركاء ومنع التعارض التشغيلي، تُطبق القواعد التالية:

1. **أولوية خدمات القاعة الداخلية:** إذا كانت القاعة المحددة تقدم خدمات إضافية (مثل: الضيافة، التوثيق والتصوير، الإضاءة، إلخ)، يتم تفعيل وإظهار الخدمات الإضافية الخاصة بالقاعة أولاً.
2. **حظر تداخل المزودين المستقلين:** يُحظر اقتراح أو إظهار مزودي خدمات خارجيين مستقلين من نفس الفئة المعروضة ضمن خدمات القاعة لتفادي تضارب المواعيد والازدواجية البرمجية والتشغيلية.

## 2. محرك العمولات الديناميكي وحساب الاشتراكات (Platform Commission Engine)

تعتمد منصة "ليلة" نظام عمولات ديناميكي ربحي مرتبط بنوع باقة اشتراك المزود النشطة:

```
                  ┌────────────────────────────────────────┐
                  │          حجز قاعة / طلب خدمة            │
                  └───────────────────┬────────────────────┘
                                      │
                                      ▼
                        ┌───────────────────────────┐
                        │ فحص باقة اشتراك المزود     │
                        └─────────────┬─────────────┘
                                      │
         ┌────────────────────────────┼────────────────────────────┐
         ▼                            ▼                            ▼
┌──────────────────┐        ┌──────────────────┐        ┌──────────────────┐
│  الباقة الأساسية │        │  الباقة المتقدمة │        │ الباقة الاحترافية│
│  (مثال: 15% عمولة)│        │  (مثال: 10% عمولة)│        │  (مثال: 5% عمولة) │
└────────┬─────────┘        └────────┬─────────┘        └────────┬─────────┘
         │                            │                            │
         └────────────────────────────┼────────────────────────────┘
                                      │
                                      ▼
                  ┌────────────────────────────────────────┐
                  │ احتساب واقتطاع صافي عمولة منصة ليلة     │
                  └────────────────────────────────────────┘
```

### 2.1 القواعد المباشرة للعمولة
- **مصدر إيراد سيادي:** اقتطاع نسبة العمولة آلياً فور تأكيد الحجز أو الطلب.
- **التحديد الديناميكي:** تُحتسب النسبة بناءً على معرف باقة الشريك النشطة المخزنة بالنظام.
- **استثناء الحملات التسويقية:** تُحسب عمولة المنصة لخدمات الوكالة الإعلانية والتسويق بناءً على "نسبة المنصة المقتطعة من أتعاب التسويق (%)" المحددة في الإعدادات السيادية.

## 3. التحليلات المالية والتشغيلية الموحدة (Combined Financial Analytics)
- عند احتساب المؤشرات المالية، الإحصائيات، والتقارير في المنصة، يتم دمج مبيعات وإيرادات **حجوزات القاعات (Venues)** مع **طلبات الخدمات المساندة (Services)** تلقائياً للحصول على رؤية مالية شاملة ودقيقة، مع توفير خيارات تصفية مستقلة لمن يرغب بالاستعراض المنفصل.
