## 2. مخطط تدفق إضافة قاعة/خدمة واعتمادها (Asset Approval Lifecycle)

```
[الشريك Provider]              [خادم المنصة Server]              [الإدارة Admin]
        │                                │                               │
  1. رفع صور ومعلومات القاعة ──────────►│                               │
        │                                │                               │
        │ (تطبيق شروط الأبعاد والحجم)   │                               │
        │                                ├─ إنشاء الحالة: Pending ──────►│
        │                                │ (حظر العرض العام للعملاء)     │
        │                                │                               │
        │                                │◄─── 2. المراجعة والاعتماد────┤
        │                                │ (تحويل الحالة إلى Approved)   │
        │                                │                               │
  3. إشعار النشر والاعتماد ◄─────────────┼─ تفعيل العرض العام بالمنصة ──►│
```
