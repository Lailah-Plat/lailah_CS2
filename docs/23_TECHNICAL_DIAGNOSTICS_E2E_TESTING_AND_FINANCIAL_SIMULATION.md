# 🧪 وثيقة التشخيصات والاختبارات الفنية، فحص الصالات ومحاكاة القرارات المالية
**Technical Diagnostics Suite, E2E Venue Test Runner & Financial Simulation Engine**

---

## 1. جناح التشخيصات والاختبارات الفنية الآلية (Automated Diagnostics Suite)

تتضمن منصة **ليلة** نظام تشخيص واختبار ذاتي مؤتمت بالكامل يُجري فحوصات دورية وشاملة على جميع المسارات والنقاط الحساسة في المنظومة لضمان سلامة الأكواد والعمليات قبل وبعد كل تحديث برمجي.

```
+-----------------------------------------------------------------------------------+
|                        Lailah Automated Diagnostic Engine                         |
+-----------------------------------------------------------------------------------+
|  [🏢 فحص الصالات والقاعات E2E] [🛍️ فحص الخدمات والتركيب] [💳 محاكاة السياسات المالية] |
|  [🔒 فحص عزل البيانات والحماية] [📡 فحص بوابات الدفع والـ API] [⚡ التنبيهات الفورية] |
+-----------------------------------------------------------------------------------+
```

## 2. محاكي دورة الحجوزات وفحص الصالات المكتمل (E2E Venue Test Runner)

يُجري النظام محاكاة كاملة ودورية لدورة حياة حجز القاعات والأماكن للتأكد من الموثوقية العالية بدون التأثير على البيانات الحقيقية للعملاء والشركاء.

```
[بدء فحص E2E] ──► [اختيار قاعة وهمية للتست] ──► [تحديد التواريخ والضيوف] ──► [اختيار خدمات مضافة]
                                                                                │
                                                                                ▼
[توليد المعاملات REV/EXP] ◄── [تأكيد الحجز BKG وإصدار INV] ◄── [محاكاة بوابة الدفع الآمنة]
```

### 2.1 مراحل محاكاة فحص الصالات والقاعات
1. **إنشاء بيئة الفحص المعزولة (Sandbox Environment):** استخدام بيانات معزولة ومؤقتة.
2. **محاكاة عملية البحث والتصفية:** تنفيذ استعلامات البحث بصفحة استكشف والتأكد من استرجاع القاعات المعينة وسرعة الاستجابة (< 200ms).
3. **محاكاة حجز قاعة وتوليد المعرفات القياسية:**
   - إنتاج معرف حجز افتراضي بدقة `BKG-26-0000000001`.
   - إنتاج الفاتورة الضريبية الصادرة `INV-260000000001` دون واصلة بعد السنة.
4. **تدقيق التسوية المالية وعمولة المنصة:** التأكد من اقتطاع نسبة العمولة بناءً على باقة الاشتراك النشطة واستخراج صافي القيمة المخصصة للـ `REV-26-0000000001`.

## 3. محاكي تفاعلية الخدمات المساندة وقواعد التسعير الهجين (Addons & Hybrid Pricing Diagnostics)

يتحقق هذا التشخيص آلياً من تطبيق **قواعد نموذج التسعير الهجين ومنع ازدواجية الخدمات**:

1. **فحص حظر الخدمات الخارجية المستقلة:**
   - إذا كانت القاعة المنسوخة بالمنظومة توفر خدمة مدمجة تحت فئة معينة (مثل: الضيافة والبوفيه)، يُحاكي التشخيص عملية حجز القاعة وتأكيد حجب جميع الموردين الخارجيين المستقلين من نفس الفئة.
2. **فحص إصدار طلبات الخدمات المستقلة `SRV`:**
   - محاكاة طلب خدمة مستقلة وتوليد معرف الطلب القياسي `SRV-26-0000000001` والفاتورة `INV-260000000001`.

## 4. محاكي القرارات والسياسات المالية السيادية (Financial Policy Simulation Engine)

أداة محاكاة برمجية متقدمة تتيح للإدارة المتاحة تجربة واختبار التغييرات المخططة على العمولات أو باقات الشركاء قبل سريانها في البيئة الحية.

```
                 ┌───────────────────────────────────────────────┐
                 │    محاكي السياسات والقرارات المالية السيادية │
                 └───────────────────────┬───────────────────────┘
                                         │
 ┌───────────────────────────────────────┴───────────────────────────────────────┐
 │                                                                               │
 ▼                                                                               ▼
┌─────────────────────────────────────────────┐ ┌─────────────────────────────────────────────┐
│       محاكاة تعديل نسبة عمولة باقة          │ │       محاكاة تغيير أتعاب التسويق            │
│ • قياس الأثر المالي على إيرادات المنصة REV │ │ • قياس الأثر على اشتراكات الشركاء           │
│ • التنبؤ بصافي أرباح المنصة المجمعة        │ │ • احتساب الضريبة المستحقة ZATCA 15%        │
└─────────────────────────────────────────────┘ └─────────────────────────────────────────────┘
```

### 4.1 خطوات وآلية عمل المحاكي المالي
- **إدخال المعايير المقترحة:** (مثال: تخفيض عمولة الباقة المتقدمة من 10% إلى 8% أو تعديل أتعاب التسويق).
- **إعادة تشغيل بيانات الحجوزات التاريخية:** تشغيل المحاكاة على بيانات آخر 12 شهراً لحساب الفروقات المالية بدقة متناهية.
- **توليد تقرير المقارنة والأثر المالي:** استخراج تقرير المقارنة المالي لحساب الفارق في الأرباح السيادية `REV` والمصروفات `EXP` قبل اعتماد القرارات الرسمية.
