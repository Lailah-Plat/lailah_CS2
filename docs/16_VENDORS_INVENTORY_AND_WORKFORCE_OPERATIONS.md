## 1. وحدة إدارة الموردين والتعاقدات الخارجية (External Vendors Management)

تتيح هذه الوحدة للشركاء ومزودي القاعات التعاقد وإدارة الموردين الخارجيين للتجهيزات الخاصة (مثل: متعهدي الذبائح، موردي الزهور والنباتات، شركات الحراسات والأمن، وموردي معدات الإضاءة والصوت).

### 1.1 معايير وإجراءات إدارة الموردين
- **سجل الموردين المعتمدين (Vendor Directory):** تسجيل اسم المؤسسة، السجل التجاري، بيانات التواصل، والفئة التشغيلية.
- **حظر التعارض مع قاعدة نموذج التسعير الهجين:** يقتصر استخدام المورد الخارجي على التجهيزات والتشغيل الداخلي للقاعة، ويُمنع عرض المورد الخارجي كخدمة مستقلة للعميل إذا كانت القاعة توفر نفس الفئة بشركائها المباشرين.

## 2. وحدة إدارة المخزون والأصول بالقاعات (Hall Physical Inventory & Asset Tracking)

نظام إدارة الأصول المادية والمعدات داخل المنشآت والقاعات لضمان الاستعداد الجاهز للفعاليات ومنع الفقدان أو التلف.

```
+-----------------------------------------------------------------------------------+
|                        Lailah Physical Inventory Management                       |
+-----------------------------------------------------------------------------------+
|  [🛋️ الأثاث والديكور]      [🍽️ معدات الضيافة والبوفيه]    [🔊 أجهزة الصوت والإضاءة] |
|  [❄️ التكييف والمولدات]     [💻 شاشات LED والبروجكتر]      [🚗 معدات الفاليه والأمن] |
+-----------------------------------------------------------------------------------+
```

### 2.1 وظائف وأدوات إدارة المخزون
1. **جرد ومتابعة أعداد العناصر:**
   - متابعة كميات الطاولات، الكراسي، الأطقم الفاخرة، أدوات الضيافة، والمعدات الصوتية.
   - تحديد الحد الأدنى لتنبيهات إعادة التزويد أو الصيانة (`Safety Stock Alert`).
2. **سجل الصيانة والإهلاك:**
   - جدولة الصيانة الدورية لأجهزة التكييف والأنظمة الصوتية وشاشات العرض.
   - تسجيل حالات التلف والتأمين المقتطع عند حدوث أضرار أثناء المناسبات.

## 3. وحدة إدارة العاملين التشغيليين والصلاحيات الميدانية (Workforce Management & Field Controls)

إدارة وتوزيع الطواقم البشرية التشغيلية (المنظمين، الصبابين والقهوجية، مشرفات القاعات، رجال الأمن، طاقم النظافة والخدمة الميدانية) أثناء تنفيذ المناسبات.

```
[جدول الفعالية BKG] ──► [تحديد الاحتياج البشري] ──► [تعيين المشرفين والطواقم] ──► [تسجيل الحضور بالموقع] ──► [إغلاق المناسبة وتقييم الأداء]
```

### 3.1 جدول الأدوار والصلاحيات الميدانية (Field Workforce Permissions)

| المسمى الوظيفي الميداني | الصلاحيات والمهام المسموحة في تطبيق الجوال/الويب | الحدود والقيود الأمنية |
| :--- | :--- | :--- |
| **مشرف القاعة (Venue Supervisor)** | متابعة دخول الضيوف، توجيه الطواقم، وتحديث حالة الحجز `In Progress`. | حظر الوصول للبيانات المالية أو إلغاء الحجوزات. |
| **مسؤول الضيافة (Catering Lead)** | إشراف على استلام الوجبات، البوفيه، وجاهزية المشروبات. | حظر تعديل أسعار أو تفاصيل العقد. |
| **فني الصوت والإضاءة (AV Tech)** | تشغيل الأنظمة الصوتية والشاشات والإضاءة وفق جدول العروسين. | الوصول مقصور على لوحة تحكم التجهيزات المباشرة. |
| **فريق الاستقبال والنظافة (Staff)** | تسجيل الحضور والغياب، وتنفيذ التوجيهات التشغيلية. | حظر الوصول لأي بيانات للعملاء أو الأسعار. |
