# 👑 وثيقة لوحة تحكم الإدارة العامة والرقابة السيادية
**Admin Master Dashboard, Asset Approval Engine & Platform Governance**

## 1. نظرة عامة على لوحة تحكم الإدارة (Master Admin Dashboard Overview)

تُمثل لوحة تحكم الإدارة العامة في منصة **ليلة** المركز السيادي والرقابي الأغلى والأشمل لإدارة المنظومة بأكملها، وتمتلك الصلاحيات المطلقة لمراقبة كافة الأنشطة التشغيلية والمالية والأمنية.

```
+-----------------------------------------------------------------------------------+
|                        Lailah Master Admin Governance Dashboard                   |
+-----------------------------------------------------------------------------------+
|  [📈 الإحصائيات الشاملة]   [👥 إدارة المستخدمين]    [🏛️ اعتماد القاعات والخدمات]     |
|  [💰 المركز المالي والضرائب] [🎟️ الفواتير الموحدة]    [📊 العمولات والاشتراكات]         |
|  [📢 تسويق الحسابات]      [🎧 تذاكر الدعم والرسائل]  [⚙️ الإعدادات السيادية للنظام]  |
+-----------------------------------------------------------------------------------+
```

## 2. محرك اعتماد القاعات والخدمات المستقلة (Asset Approval Engine)

تخضع جميع القاعات والخدمات المساندة المضافة حديثاً لنظام تدقيق وحوكمة محكم قبل السماح بنشرها للعملاء:

```
[المزود يضيف قاعة/خدمة] ──► [إنشاء بحالة Pending] ──► [لوحة الإدارة: قسم الاعتمادات]
                                                              │
                                        ┌─────────────────────┴─────────────────────┐
                                        ▼                                           ▼
                             [الموافقة: Approved]                         [الرفض: Rejected]
                                        │                                           │
                             [تفعيل العرض العام بالمتجر]                 [إرسال سبب الرفض للمزود]
```

### 2.1 خطوات وآلية الاعتماد من الإدارة
1. **استلام التنبيه:** ورود إشعار فوري بقسم "طلبات اعتماد الأصول الجديدة" بظهور عنصر جديد بحالة `pending`.
2. **الفحص والتدقيق الفني:**
   - مراجعة اسم القاعة/الخدمة والوصف والموقع الجغرافي.
   - التدقيق في أبعاد الصور المرفوعة والتأكد من مطابقتها لنسبة `16:9` وحجم لا يتجاوز `500KB`.
   - التأكد من سلامة مقطع الفيديو التوضيحي (`MP4` بحد أقصى `10MB`).
   - مراجعة أسعار الحجز والخدمات المضافة والتأكد من واقعيتها.
3. **قرار الاعتماد أو الرفض:**
   - **عند الموافقة:** تحويل الحالة إلى `approved` لتظهر فوراً بمتجر العملاء على كافة التطبيقات والمنصات.
   - **عند الرفض:** تحويل الحالة إلى `rejected` مع إدخال سبب الرفض ليصل تنبيه للمزود لتصحيحه.

## 3. الرقابة المالية وإصدار الفواتير الضريبية الموحدة (Unified Tax Invoices & Finance)

### 3.1 إصدار الفاتورة الضريبية الموحدة (Unified Tax Invoice)
- **الصلاحية الحصرية:** تُصنع وتُصدر الفاتورة الضريبية الموحدة حصرياً من حساب الإدارة العامة (`Admin`).
- **محتويات الفاتورة الموحدة:**
  - إجمالي قيمة الحجوزات وطلبات الخدمات بالمنصة.
  - إجمالي العمولات المقتطعة لصالح المنصة.
  - حصة ضريبة القيمة المضافة المجمعة (VAT 15%).
  - البيانات الضريبية الرسمية لشركة منصة ليلة ورقم التسجيل الضريبي.

### 3.2 التحكم بالإعدادات المالية السيادية (Sovereign Financial Settings)
- **نسب العمولات الافتراضية:** تحديد نسبة العمولة لكل باقة اشتراك (أساسية، متقدمة، احترافية).
- **نسبة اقتطاع أتعاب الحملات التسويقية (%):** تحديد نسبة المنصة من أتعاب الوكالة الإعلانية والتسويق للمزودين.
- **إدارة الحسابات البنكية للمنصة:** ضبط وتحديث بيانات الحسابات البنكية المستقبلة للمدفوعات.

---

## 4. حوكمة المستخدمين وإدارة الحسابات (User & Tenant Governance)
1. **مراقبة الحسابات والتراخيص:** استعراض جميع حسابات العملاء والشركاء مع إمكانية مراجعة السجلات التجارية والرقم الضريبي.
2. **إدارة حالات الحساب:**
   - التفعيل والاعتماد.
   - التعليق والحظر مؤقتاً عند المخالفة التشغيلية.
3. **إعادة ضبط وتوليد كلمة المرور والبيانات:** تقديم الدعم الفني المباشر لحسابات الشركاء والعملاء.
